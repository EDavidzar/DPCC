# DPCC

PROGRAMA DE AYUDA PARA EL CUMPLIMIENTO DE LA LEY DE PROTECCIÓN DE DATOS EUROPEA

El programa ayuda las empresas a cumplir sus obligaciones con respecto a la protección de datos personales. Se utiliza un servidor de base de datos MYSQL/MARIADB en los que se introducen los datos necesarios para el cumplimiento de la LOPD y se pueden crear varios documentos y anexos necesarios.

Ha sido desarrollado en el lenguaje de programación Java y se puede ejecutar en cualquier sistema/entorno operativo en el que se pueda instalar, esté instalado y configurado  Java Runtime Environment (JRE). versión mínima 17.0 de Java Runtime Environment (JRE).

# DPCC

PROGRAM TO ASSIST WITH COMPLIANCE WITH THE EUROPEAN DATA PROTECTION LAW

The program helps companies meet their obligations regarding the protection of personal data. It uses a MySQL/MariaDB database server into which the data required for compliance with the Data Protection Act is entered, and various necessary documents and attachments can be created.

It has been developed in the Java programming language and can run on any system or operating environment where the Java Runtime Environment (JRE) can be installed, is installed, and is configured. Minimum version 17.0 of the Java Runtime Environment (JRE) is required.
